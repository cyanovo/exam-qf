## 本次修复

1. 正式首页误加载 Vite 开发客户端，导致页面卡住并出现 `__DEFINES__` 异常。
2. 发布配置缺少 Druid 必需参数，导致启动失败。
3. MySQL 文件执行方式与当前客户端不兼容。
4. 恢复后的私有文件目录名与系统实际读取约定不一致。
5. 自动部署按目录名排序，可能选中较旧版本；改按清单构建时间选择。
6. 设备可选联系方式、备注为 null 时校验或保存失败；统一为空字符串并加入测试。

不合格中间构建已移出 releases，放入本机 `.runtime-release/rejected`，不参与自动部署。

## 边界

- 本版为当前 Windows 电脑的升级和本机运行版本，不是无需环境的新电脑安装包。
- 尚未完成 PRD 的 Linux / Docker / Nginx 正式拓扑交付、200 人负载测试、全面安全验收。
- 4 项需额外环境的测试被跳过；不能把本次结果理解为整个系统无 bug。
- 回滚恢复兼容程序版本，不自动回退业务数据或删除新增数据库字段。
- 自动备份计划需按说明主动注册；本次未安装计划任务。
- 账号文档包含全部 24 条记录（含 5 条已删除记录）；17 条密码经离线核验，7 条未知。两个未删除账号 STU1、STU2 的原密码未知，没有擅自重置。
