| 账号 | 用途 |
|---|---|
| demo_owner | 创建任务、绑定裁判、发布、审批评分撤回、锁定、绑定成绩复核员、提交复核 |
| demo_judge | 为绑定任务中的考生逐项打分、保存草稿、提交、申请撤回 |
| demo_reviewer | 对绑定考试进行独立复核及成绩发布 |

建议用不同浏览器配置或隐私窗口切换账号。演示环境包含从旧备份恢复的数据和合成的 910xx 测试数据；只有明确标记的演示考试用于本次验证。

## 演示步骤

1. 进入考试 91002（Onsite interactive demo），已有“程序讲解与现场演示”任务，满分 30，裁判是 demo_judge。
2. 用裁判账号打开考生评分。已有可继续编辑的 25 分草稿，调整两项分数并提交。
3. 提交后不可直接改分。裁判申请撤回，负责人填写原因批准，裁判才能重新编辑并提交。
4. 负责人锁定现场任务，进入成绩复核页并提交复核。理论部分预置 8 分，现场任务分真实由裁判填写。
5. 复核员在成绩复核列表中批准并发布；学生在本人成绩页查询。负责人或评分参与者不能自行复核其经手成绩。
6. 考试 91005 已完整验证并发布：理论 8 + 现场 27 = 35，满分 40。91001、91003 保留了首次权限联调的中间记录，不是验收成功样例。

## 本轮实现

- 任务名称、说明、演示时长、裁判、多个整数评分项及满分。
- 草稿任务发布，任务内考生名单，绑定裁判逐项评分及备注。
- 评分草稿、提交锁定、独立撤回审批、评分版本冲突检查。
- 全员提交后锁定任务，成绩进入复核后阻止现场修改。
- 创建/发布/保存/提交/撤回/锁定操作审计和评分前后快照。
- 现场分合入已有成绩快照、排名、统计、独立复核发布、个人查分和 CSV 明细。
- 补齐原先缺失的普通负责人阅卷权限菜单定义，未向无关角色自动授权。

## 部署与重启

本次包：`cyan-exam/cyan-exam-admin/target/cyan-exam-admin-onsite-demo.jar`。
日志：`D:/app/cyan-exam/onsite-demo-out.log`、`D:/app/cyan-exam/onsite-demo-err.log`。

新环境须先完成原有考试、快照、会话、判分、成绩、编程表迁移，再执行：

1. `cyan-exam/sql/exam_grading_permissions.sql`
2. `cyan-exam/sql/exam_result_permissions.sql`
3. `cyan-exam/sql/exam_onsite.sql`
4. 仅全新本机演示库可执行 `cyan-exam/sql/exam_onsite_demo.sql`；该脚本显式指定演示库，不可用于生产。

后端重启须保留数据库指向、8081 端口、loopback 监听、Redis DB 2 和独立 `TOKEN_SECRET`。更换密钥后需要重新登录。评测执行保持 `EXAM_JUDGE_ENABLED=false`，不要在业务主机运行考生代码。

前端启动示例（在 `cyan-exam-vue` 目录）：

```powershell
$env:EXAM_API_TARGET='http://127.0.0.1:8081'
npm run dev -- --host 127.0.0.1 --port 5176 --strictPort
```
