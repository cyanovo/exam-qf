核对日期：2026-10-29。

需求来源：[python-prd-v1-0-1.md](D:/桌面/python-prd-v1-0-1.md)。文件名为 v1-0-1，正文标注 V1.0、待项目评审签发。本表将其作为需求对照，不视为已签发验收结论。

## 1. 结论与统计口径

当前已部署的是理论考试基础版本及考试资源权限修复，不是完整的 Python 实操竞赛平台。自动判分、在线编程、成绩复核发布等新代码已有实现，但没有替换正在运行的后端；不能算作现在线上可用。

| 标记 | 含义 |
|---|---|
| 已部署基础功能 | 部署记录和代码支持其存在；不表示已完成全部真实账号、真实业务现场验收 |
| 待部署实现 | 源码和开发验证已有对应实现，但当前运行版本不提供该完整能力 |
| 部分实现 | 只覆盖需求的一部分，仍有规则、流程或安全验收缺口 |
| 未实现 | 未发现满足该需求的完整业务实现，通用组件不能代替业务闭环 |
| 待验收 | 缺少真实环境验证证据，不能判为通过 |

这些标记可以同时出现，例如一个模块可以“基础功能已部署，增强功能待部署，整体部分实现”。不以页面数量、接口数量或测试用例通过率推算需求完成率。

运行版本核对：8080 后端进程 PID 47884 使用 `D:/app/cyan-exam/releases/20261029-ownership/cyan-exam-admin-ownership.jar`。新包为 `cyan-exam-admin-results-coding.jar`，尚未部署。新开发前端连接旧后端，不代表新接口可用。

## 7. 不应算作首版缺失的内容

文档明确不要求平台直接控制机器人动作，也不要求首版实现多租户多校区、完整云 IDE、虚拟机自动发放、可视化模型训练或摄像头/人脸监考。设备台账是 P1。移动端正式编程考试不作为桌面端要求的替代验收目标。

Java 21、Redis Streams 等技术选型建议不能直接等同于缺失功能；当前使用 Java 17 和数据库持久队列，应按兼容性、可靠性、安全和性能验收。接口草案路径不同，也不自动构成功能缺失。
