# Git 基线与后续开发口径

日期：2026-10-29。

## 保存范围

首次提交保存当前前后端源码、SQL、测试、文档和主前端依赖锁文件。此基线包含尚未部署的自动判分、编程和成绩流程代码，不表示这些功能已经上线。

不纳入 Git 的内容：

- node_modules、target、dist、测试报告及日志等可重新生成的文件。
- 本地 Redis 程序目录、Redis 持久化数据。
- 含本机数据库口令和令牌密钥的 application.yml、application-druid.yml。

这些文件仅被忽略，没有删除或修改。Git 基线是代码回退点，不是完整的数据库、配置、上传文件或运行环境备份。其他机器恢复时需要单独提供配置，并安装依赖、初始化数据库。

## 用户确认的优先级

当前优先补齐功能，让业务流程可以展示和演示；距离正式投入使用还有时间，不以完成正式上线验收作为继续开发的前置条件。

- 优先建设可操作、有数据流转的业务功能，不只制作静态页面。
- 演示数据或模拟服务必须明确标注，不冒充真实代码执行或真实评测结果。
- 权限范围、数据保护、评分准确性及学生代码隔离执行仍是基本约束。
- 正式并发压测、完整安全验收、整体恢复演练及生产发布，在正式使用前另行完成。
- 本次创建 Git 基线不更换正在运行的后端，也不修改生产数据库。

功能范围以 [PRD 对比表](D:/work/cyan-exam-main/docs/prd-feature-comparison-20261029.md) 为依据，但按演示业务流程优先安排开发。
