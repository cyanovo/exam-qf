## 推荐演示流程

1. 管理账号进入“考试与编排”，新建未来时间的考试并配置考生名单。
2. 在“章节与题目顺序”中新增机器人实操编程题，设置裁判和逐步评分项；已有理论题由原组卷入口选择。
3. 配置章节、提示、顺序、个人时长、入场窗口、同分规则和成绩公开范围，然后保存、统一发布。
4. 考生在同一份试卷内作答，机器人实操题在线编写并提交代码，无需答辩或额外上传成果；异常通过“异常与材料”提报。裁判查看提交代码，观察实际机器人运行后逐步评分。最新流程见 `robot-practical-workflow-20261029.md`。
5. 管理人员受理并解决异常，绑定的独立复核员审批。裁判完成任务评分，管理人员锁定任务评分。
6. 场次结束或人工终止后，提交成绩复核；复核员审批并发布，考生按公开策略查看成绩。
7. 成绩发布且异常全部审批完成后归档，历史和材料仍可查询，业务修改入口关闭。

## 明确未包含

- 文件没有接入杀毒引擎；当前仅允许 PNG/JPEG/TXT/CSV/JSON/PY，不支持 ZIP、PDF、Office 等格式。
- 保留期清理由管理员手动触发，尚无自动调度及物理删除失败重试队列；删除失败会留日志，数据库删除标记及审计保留。
- 导出采用“普通脱敏 / 获授权显示身份”的字段策略，尚不是任意角色自定义列的配置器。
- 章节采用编排条目级配置；现场任务当前以创建、发布、评分为主，未实现独立章节库和完整任务编辑/删除管理。
- 本次没有重新完成 Python 沙箱生产隔离审计、负载测试或真实摄像头录制验收；摄像头沿用本机预览，不录制、不上传。
- 历史账号是否需要强制改密按 `pwd_update_date` 是否为空判断；没有批量清空所有老账号的改密时间。
